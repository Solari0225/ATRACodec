# Changes / 变更记录

## 0.5.0-test1

首个 ATRACodec 独立仓库公开快照。包括 22 档有损/无损编解码、增量 C API、CLI、Windows 与 macOS 原生双语测试界面、SDK 和 C11 示例。加入来源核验、流式处理约定、验收边界、中英文 README 和 GPL-3.0-only 许可证。

First public snapshot in the independent ATRACodec repository: 22 lossy/lossless profiles, incremental C API, CLI, native bilingual Windows/macOS test converters, SDK, and C11 examples. Adds provenance, pipeline contracts, scoped validation notes, Chinese/English READMEs, and GPL-3.0-only licensing.

程序和库沿用已验收的 0.5.0-test1 构建；发布整理没有修改其字节。macOS 原生执行、GUI 手动操作及 Walkman 实机验证仍待完成。

Programs and libraries retain the accepted 0.5.0-test1 build bytes. Publication packaging did not modify them. Native macOS execution, manual GUI operation, and Walkman hardware validation remain outstanding.
